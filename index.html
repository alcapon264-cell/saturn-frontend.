Jupiter Perps /market-stats — 4-sample live check

This performs 12 read-only GET requests: SOL, ETH and BTC, four rounds total. Requests are spaced 5 seconds apart, so each market is sampled about every 15 seconds. Total run time is about 60 seconds.

No API key, cookies, wallet, signing or trading. Nothing is sent anywhere except Jupiter's fixed public API, and nothing is saved unless you tap Download JSON.

Browser limitation: the page can only read response headers exposed by Jupiter's CORS policy. Missing rate-limit headers here do not prove that no limits exist. This check records what the browser can observe.

Ready. Run once and wait for all 12 requests to finish.
