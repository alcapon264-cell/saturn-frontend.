Jupiter Perps /market-stats — read-only check

Sends 3 GET requests (SOL, ETH, BTC), 5 s apart. No API key, no cookies, nothing is written anywhere. Open it from the same origin you use for Saturn (for example a page on your GitHub Pages site) so CORS matches.

Limit of a browser run: a page can only see response headers that Jupiter lists in Access-Control-Expose-Headers (plus a few safe ones). If no rate-limit header appears here, that does not prove there is none. Use node scripts/live-check.mjs for the full header list.
